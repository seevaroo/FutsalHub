1. Ringkasan Eksekutif (Executive Summary)

FutsalHub adalah platform web reservasi lapangan futsal modern yang dirancang untuk mengotomatisasi seluruh siklus bisnis penyewaan lapangan olahraga. Platform ini memfasilitasi transaksi multi-kanal (QRIS otomatis/manual & Cash di kasir), verifikasi pembayaran dua arah, notifikasi visual mengambang (Dynamic Island), modul manajemen data pelanggan dengan WhatsApp direct chat (+62), serta rekapitulasi laporan transaksi real-time.

Tujuan Utama Produk (Product Goals)
Meniadakan risiko bentrok jadwal (double-booking), menggantikan pencatatan manual berbasis buku/WhatsApp dengan sistem real-time, memfasilitasi opsi pembayaran multi-kanal (QRIS digital & Cash di kasir), serta menyajikan laporan keuangan dan okupansi lapangan yang akurat bagi pengelola.

1.1 Masalah Bisnis & Solusi FutsalHub

Tantangan Operasional Dampak Negatif Manual Solusi Terintegrasi FutsalHub
Jadwal Tumpang Tindih Dua tim bertanding di jam yang sama akibat kelalaian jadwal; komplain pelanggan tinggi. Slot Locking Engine: Slot jam otomatis terkunci saat reservasi dibuat; validasi ketersediaan real-time hingga level detik.
Verifikasi Pembayaran Lambat Bukti transfer tercecer di chat WhatsApp pribadi kasir tanpa nomor referensi pesanan. Dedicated Verification Workflow: Bukti QRIS tersimpan rapi per ID pesanan lengkap dengan opsi Approve/Reject dan Konfirmasi/Batal Cash.
Kontak Customer Terpencar Admin kesulitan menghubungi pelanggan untuk konfirmasi booking atau mengelola akun member. Customer Module + WhatsApp (+62): Data member terpusat dengan link langsung chat WhatsApp resmi dan manajemen status akun (Dihapus Admin vs Dihapus User).
Rekap Pendapatan Rumit Penyusunan laporan bulanan memakan waktu; risiko salah hitung kas fisik di lapangan. One-Click Reporting & Print: Filter periode fleksibel, ekspor data, dan format cetak resmi (print layout) siap audit.

3. Alasan Pemilihan Stack Teknologi (Technical Rationale)

Backend Kenapa Laravel 13 & PHP 8.5.12?
1. Kecepatan & Keamanan: Berjalan di atas PHP 8.5.12 dengan optimasi memori, middleware otorisasi berbasis peran (RBAC), perlindungan CSRF, dan pencegahan SQL Injection via PDO.
2. Eloquent ORM & SoftDeletes: Mempermudah relasi antar entitas (User, Booking, Field, Payment) dan pengarsipan data aman saat akun dihapus tanpa merusak histori audit.
UI Styling Kenapa Tailwind CSS v4?
1. Desain Cepat & Konsisten: Menggunakan class utility terstandarisasi yang menghasilkan tampilan modern bergaya Dark Luxury Sports Arena.
2. Zero Runtime Overhead: Kompilasi berbasis Rust yang sangat ringan dan performa rendering visual instan di semua ukuran layar.
Frontend Kenapa Blade + Vanilla JS?
1. Kecepatan SSR: Halaman langsung dirender utuh dari server ke peramban tanpa jeda download bundle JS client-side yang berat.
2. Ringan & Bebas Dependensi: Vanilla JS menjaga ukuran bundle tetap kecil dan bebas dari kerentanan dependensi pihak ketiga.
Database Kenapa MySQL Relasional?
1. Integritas ACID: Reservasi lapangan menuntut konsistensi absolut agar tidak terjadi slot ganda (double-booking).
2. Relasi Terstruktur: Relasi multi-slot (1 to Many) dan bukti bayar (1 to 1) termodelkan secara rapi dan dapat diandalkan.

4. Perincian Fitur Aplikasi (Product Functional Specifications)

4.1 Modul Pengguna & Autentikasi (Auth & User Lifecycle)

  • Dua Jalur Akses Awal (Start / Buka Web):
    • Pengguna Baru (Belum Punya Akun): Membuka halaman pendaftaran akun baru (/register) → mengisi Nama, Email, Password, dan Nomor WhatsApp (otomatis terformat +62) → klik "Daftar Akun" → sistem memproses registrasi lalu otomatis me-redirect ke Halaman Login (/login) disertai notifikasi Dynamic Island: "Akun berhasil dibuat! Silakan masuk dengan email dan password Anda." → pengguna memasukkan kredensial login.
    • Pengguna Terdaftar (Sudah Punya Akun): Langsung membuka Halaman Login (/login) → memasukkan email dan password terdaftar.
  • Validasi Status & Kredensial Akun (Security Check):
    • Jika akun dihapus mandiri oleh pengguna (deleted_by = 'user'): Login ditolak dengan notifikasi Dynamic Island: "Akun Anda telah dihapus oleh pengguna dan tidak dapat dipulihkan."
    • Jika akun dihapus oleh admin (deleted_by = 'admin'): Login ditolak dengan notifikasi Dynamic Island: "Akun Anda telah dinonaktifkan atau dihapus oleh administrator."
    • Jika kredensial tidak cocok: Notifikasi kesalahan email atau password.
  • Diferensiasi Notifikasi Berhasil Login (Dynamic Island):
    • Akun Baru (First-time Login setelah Register): Diarahkan ke Beranda Customer dengan sambutan: "Selamat datang di FutsalHub, [Nama Customer]!"
    • Akun Lama (Returning Customer): Diarahkan ke Beranda Customer dengan sapaan hangat: "Selamat datang kembali di FutsalHub, [Nama Customer]!"
    • Role Administrator: Diarahkan langsung ke Panel Admin Dashboard (/admin/dashboard).
  • Dynamic Island Toast on Logout: Notifikasi melayang elegan di halaman login saat pengguna keluar: "Anda telah berhasil logout."

4.2 Modul Customer (Antarmuka Penyewa Lapangan)

Beranda Home & Showcase Arena
• Hero Section Rapi: Judul FutsalHub, ilustrasi lapangan transparan, deskripsi arena, dan tombol CTA reservasi cepat.
• Mobile Swipe Carousel: Khusus perangkat seluler, katalog lapangan disajikan dalam format carousel geser (swipe) interaktif.
• Edukasi Karakteristik Lantai: Informasi spesifikasi 3 tipe lantai (Vinyl FIFA, Rumput Sintetis, dan Interlock Polimer).
• 8 Fasilitas Arena: Loker, Shower Hangat, Parkir Aman, Kantin, Bola/Rompi, Free WiFi, Lampu LED, & Scoreboard Digital.
Katalog Filter & Pencarian
• Filter Tipe Lapangan: Tab kategori: Semua Lapangan, Lantai Vinyl, Rumput Sintetis, dan Interlock Modular.
• Instant Search: Pencarian real-time berdasarkan nama dan deskripsi lapangan.
• Badge Ketersediaan: Status ketersediaan (Tersedia / Sedang Dalam Perbaikan).
• Detail Modal: Popup informasi lengkap dimensi, keunggulan, dan tarif sewa per jam.
Reservasi Slot Engine Real-time
• Pemilihan Tanggal Fleksibel: Proteksi tanggal masa lalu (hanya dapat memilih hari ini ke depan).
• Disable Slot Kedaluwarsa: Jam operasional yang sudah lewat pada hari berjalan otomatis dinonaktifkan.
• Pencegahan Bentrok Jadwal: Slot yang telah dipesan terkunci otomatis via pengecekan real-time.
• Multi-Slot Booking: Penyewa dapat memilih beberapa jam sewa sekaligus dalam satu kali pemesanan.
Checkout Metode Multi-Kanal
• Pembayaran QRIS: Menampilkan QR Code resmi arena, panduan transfer, dan form upload bukti transaksi transfer bank/e-wallet.
• Pembayaran Cash: Pilihan bayar tunai di kasir arena saat datang bertanding.
• Pembatalan Mandiri: Penyewa dapat membatalkan pesanan sebelum pembayaran diverifikasi oleh admin arena.

4.3 Modul Administrator (Pengelola Arena)

Admin Verifikasi Transaksi (QRIS & Cash)
• Verifikasi QRIS: Pratinjau bukti bayar resolusi penuh via modal popup, aksi Setujui (status confirmed) dan Tolak (status cancelled).
• Verifikasi Cash di Kasir: Dua tombol aksi lengkap bagi admin: Konfirmasi (pembayaran diterima) dan Batalkan (customer tidak hadir/batal sewa).
Admin Manajemen Data Customer
• Daftar Member Lengkap: Menampilkan nama, avatar, email, kontak WhatsApp format +62, tanggal bergabung, dan jumlah total riwayat pesanan.
• Direct Chat WhatsApp: Tombol satu-klik untuk langsung membuka chat WhatsApp ke customer lengkap dengan template pesan sapaan otomatis.
• Hapus Akun & Hak Pemulihan: Akun yang dihapus admin dapat dipulihkan ("Pulihkan"), sedangkan akun yang dihapus sendiri oleh pengguna berstatus "Dihapus User" dan tidak dapat dipulihkan.

6. Arsitektur Basis Data (Database Schema & Relasi)

Struktur basis data relasional MySQL FutsalHub dirancang dengan normalisasi tingkat ketiga (3NF) guna menjamin konsistensi, integritas referensial, serta performa kueri yang optimal:

Tabel Kolom / Tipe Data Fungsi & Relasi Basis Data
users id (PK), name, email, phone, password, role, avatar, deleted_by, created_at, updated_at, deleted_at Penyimpanan akun pengguna. role: 'admin' / 'customer'. deleted_by: 'admin' / 'user' (menentukan hak pemulihan). Relasi: 1 to Many ke bookings.
fields id (PK), name, type, price_per_hour, description, image, status, timestamps Master data lapangan. type: 'vinyl', 'sintetis', 'interlock'. status: 'available', 'maintenance'. Relasi: 1 to Many ke bookings.
time_slots id (PK), start_time, end_time, timestamps Master jam operasional per 60 menit (08:00 - 22:00 WIB). Relasi: 1 to Many ke booking_details.
bookings id (PK), booking_code, user_id (FK), customer_name, customer_phone, field_id (FK), booking_date, total_price, status, cancelled_by, timestamps Header pesanan sewa. status: 'pending', 'confirmed', 'completed', 'cancelled'. cancelled_by: 'admin' / 'user'. Menyimpan snapshot nama & telepon historis.
booking_details id (PK), booking_id (FK), slot_id (FK), price, timestamps Item jam sewa lapangan yang dipesan (mendukung multi-slot pemesanan dalam satu kode booking).
payments id (PK), booking_id (FK), payment_method, proof_image, paid_at, status, timestamps Rekaman pembayaran. payment_method: 'qris', 'cash'. status: 'pending', 'verified', 'rejected'. Relasi: 1 to 1 ke bookings.

7. Persyaratan Non-Fungsional (Non-Functional Requirements)

Keamanan Security & Proteksi Data
• CSRF & XSS Shield: Setiap formulir dilindungi token CSRF dan rendering Blade melakukan auto-escape karakter HTML berbahaya.
• Password Hashing: Pengacakan sandi menggunakan enkripsi aman Bcrypt.
• Role Middleware: Pembatasan hak akses ketat antara customer dan admin melalui middleware otorisasi.
Performa Speed & Responsivitas
• Kecepatan Load Sub-Detik: Server-side rendering (SSR) dengan Blade menghasilkan respon halaman di bawah 1 detik.
• Mobile-First & Carousel: Penataan tata letak responsif dan interaksi swipe gestur di perangkat HP.
• Print Layout Otomatis: Dokumen cetak invoice dan laporan keuangan otomatis menanggalkan elemen navigasi saat dicetak.
Rencana Pengembangan Masa Depan (Product Roadmap)
1. Integrasi Payment Gateway Otomatis (Midtrans / Xendit API) untuk validasi transfer QRIS instan tanpa upload struk manual.
2. Layanan WhatsApp Broadcast Gateway (Fonnte API) untuk pengiriman tiket QR invoice otomatis langsung ke nomor HP customer.
3. Sistem Poin Loyalitas & Turnamen Mini Bracket bagi komunitas futsal terdaftar.
